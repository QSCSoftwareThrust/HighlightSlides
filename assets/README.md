Place the official full-color QSC logo here as:

```text
qsc-logo.png
```

The white/knockout QSC logo is retained as a fallback for dark-background
templates:

```text
qsc-logo-white.png
```

The current template places logos in a white band immediately above the blue
footer, so the generator prefers the full-color logo. Deck generation fails if
no QSC logo is available. Per-paper `Institution Logos` should only list the
institution(s) supported by QSC for that paper, not QSC itself.
